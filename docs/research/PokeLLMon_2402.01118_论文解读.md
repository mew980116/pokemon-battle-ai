## 状态如何转成文本（关键设计）

每个回合，环境把 battle server 的消息解析成**四部分文本**喂给 LLM：

1. **我方队伍**：场上 + 后备宝可梦的属性（种族/属性/能力/招式/HP 等）
2. **对手队伍**：场上 + 后备（部分未知）
3. **场地信息**：天气、入场钉子（entry hazard）、场地（terrain）
4. **历史回合日志**：双方之前的动作，存进一个 log queue

→ 第 4 条「历史回合日志」是论文状态描述的一部分，正是我们 TODO 里的「战报历史注入」。

## 三大策略

### 1. In-Context RL（ICRL）—— 文本反馈当"奖励"
LLM 不需要数值 reward，**上一回合的战斗文本反馈**就是 reward，边打边在线修正策略（无需训练）。反馈分四类：

| 反馈类型 | 内容 | 作用 |
|---|---|---|
| HP 变化 | 连续两回合的 HP 差 | 反映攻击招式的实际伤害 |
| 招式效果 | super-effective / ineffective / no effect（免疫） | 判断属性克制或特性/招式免疫 |
| 执行优先级 | 谁先动 | 粗略估计速度（对手精确能力未知） |
| 招式实际效果 | 能力升降、回复 HP、中毒/烧伤/冰冻等 | 捕捉状态/非攻击招式的真实后果 |

**为什么需要它**：没有反馈时，agent 会"不断重复同一个错误动作"。论文 Figure 6 的例子是——用 Crabhammer（水系）打 Dry Skin 特性的 Toxicroak（水系免疫），动画显示 "Immune"，但这条信息不在状态描述里，于是 agent 连打两回合白送对面两个免费回合强化，最终被翻盘。

### 2. Knowledge-Augmented Generation（KAG）—— 外部知识对抗幻觉
ICRL 只能"事后补救"，但有些错是**一招致命、来不及反馈**的（如派草系打火系一回合被秒）。KAG 用外部知识**事前**根治幻觉，两类：

- **KAG[Type]（属性克制）**：不在状态里只标属性让模型自己推，而是显式注入"X 克制草系、怕火系招式"这类描述。
- **KAG[Effect]（招式/特性效果）**：招式太多（919 个）记不住，从 Bulbapedia 把每个场上宝可梦的**特性效果 + 招式效果**检索出来，存进 Pokedex 图鉴，拼进状态描述。

**效果最显著**：KAG[Type] 让模型开始"在正确时机用特殊招式"——如 Klefki 用 Magnet Rise 免疫 Rhydon 的地震，而不是换人。

### 3. Consistent Action Generation —— 抑制恐慌换人
对比了三种 prompting：

- **CoT**：先想再打 → **有害**，会让模型"过度思考"，面对强敌时连续换人逃跑（panic switching），白送对面免费回合强化。
- **SC（Self-Consistency, k=3）**：独立采样 3 次动作，投票取最一致的 → **有效**，胜率反超人类。
- **ToT（Tree-of-Thought, k=3）**：生成 3 个候选自己评估 → 中等。

论文对 CoT 产生的"恐慌想法"做了定性分析：模型会写出"对手攻击已经 ×2，能秒我，我得换人…"，这种焦虑情绪驱动的思路导致连续换人而非攻击。

## 论文揭示的两大弱点（= 未来方向）

1. **怕消耗战（attrition）**：模型只追求短期收益，被"高防 + 频繁 Recover + 剧毒"的拖字诀磨死。w/ Attrition 仅 18.75% 胜率，w/o 达 53.93%。破解需要**跨回合长期规划**（先强化攻击到高位再一击致命）——论文留作未来工作。
2. **被老手欺骗（deception）**：只基于当前状态决策、不预测对手下一步，会被"先派龙系勾你用龙招、当回合换免疫的宝可梦"这类骗术骗掉强化机会。

## 与本项目的强对应（DeepSeek 接入 pokemon-battle-ai）

我们战报里暴露的 bug，论文几乎逐条命中：

| 我们战报的 bug | 论文的对应结论 | 论文解法 → 我们的做法 |
|---|---|---|
| 持续用"热水"打储水蟾蜍王（免疫） | Figure 6：无反馈则"不断重复同一错误动作" | **ICRL 反馈(2)+KAG[Effect]** → 喂对手特性 + 上一招"被吸收"反馈 |
| 对已烧伤目标用剧毒（异常互斥） | 反馈(4)：招式实际效果（异常状态） | 状态里补**异常状态**字段 |
| 死用铁头、不用克制月亮伊布的近战 | 幻觉：记错属性克制，KAG[Type] 单点增益最大（+19 AP） | **hybrid 预计算**：把 `typechart()` 克制倍率注入 prompt |
| 强制换人时仍输出 attack | （论文无直接对应，我们的环境特有） | 状态里补"场上已空、必须换人"标记 |
| —— | CoT 有害（-4）、SC 反超人类（+6） | `deepseek-v4-flash` 是推理模型，注意别让思考链破坏稳定；可引入 SC 投票 |

### 直接可落地的三条结论
1. **最优先做 KAG[Type] 等价物**：预计算每个招式对对手的克制倍率（用现有 `typechart()`），这是论文单点增益最大的一步（+19 AP）。
2. **历史回合日志 + 反馈是核心**：论文把"上一回合反馈"当作状态的一部分，恰好对应我们 TODO 的「战报历史注入」。补上后能直接修掉"持续用无效招式"这类 bug。
3. **警惕推理模型的"隐性 CoT"**：论文证明显式思考链有害（恐慌换人），我们用的推理模型自带思考，需保持"只输出 JSON、不解释"的约束，未来可加 Self-Consistency 投票兜底。
