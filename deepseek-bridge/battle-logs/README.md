# DeepSeek 对战战报存档

存放 DeepSeek 版本（`deepseek-bridge/`）的对战战报与决策质量复盘。

## 命名建议

```
battle-logs/YYYYMMDD_我方_对手.md
```

例如：`20260907_Mew_清分少女.md`

## 每篇战报建议包含

- **双方阵容**：我方 / 对手各 6 只（宝可梦、配置）
- **关键回合**：DeepSeek 的 `choice raw => ...` 与 `executed: ...` 输出摘录
- **决策质量观察**：换人 / 出招是否合理，有无明显失误
- **问题 / 待改进**：可对应 TODO.md「DeepSeek 接入」章节的待办项
